Anri's FF14 Guide ホーム画面 v1

【今回作った範囲】
・杏里が選んだ黒×ピンク×蝶×キラキラのデザイン
・スマホ縦持ちで見やすい横長カード型レイアウト
・ホーム、ジョブ選択、スキル回し、ホットバー、ボス攻略の土台
・スキル回しタブ、ボス攻略タブ、テーマ、文字サイズ、キラキラ切替
・設定はブラウザのlocalStorageへ保存

【大事な点】
・スキル回し、ホットバー、ボス情報は「見た目確認用の仮データ」です。
・最新パッチの正しい情報を確認してから正式データへ差し替えます。
・画像は、杏里が完成見本に選んだ画像から初期確認用に切り出しています。
・元の高画質SSへ後から差し替えられる構造です。

【ファイル】
index.html  ホーム画面
style.css  デザイン
app.js     タブや設定の動作
assets/    画像

【GitHubへ置く場合】
フォルダー内のファイルを同じ階層のままアップロードしてください。
最初は index.html を開いて表示を確認します。
